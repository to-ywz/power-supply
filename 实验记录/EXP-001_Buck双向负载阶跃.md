# EXP-001 Buck平均模型双向负载阶跃

记录日期：2026-10-20（北京时间）  
状态：试验已完成；问题待分析；参数为候选基线，尚未最终定型。

## 1. 项目位置与目的

整机架构：220 VAC → 110 VAC变压器 → 桥式整流及母线电容 → 同步Buck → 0–100 V可调输出。本阶段目标100 V/15 A（1.5 kW），单个86 µH电感。

本实验验证理想155 V输入下，Buck平均模型对双向负载变化的响应。未包含真实交流前端、开关纹波、器件寄生、热、EMI及保护动作；结果不能作为整机合格结论。

## 3. 操作

保持PI、输入和功率级不变，在t=1 s切换负载电导：

- 加载：0.10 S → 0.15 S，即10 Ω → 6.667 Ω。
- 卸载：0.15 S → 0.10 S，即6.667 Ω → 10 Ω。

100 V时分别对应10 A和15 A。模型使用Iload=G×Vout，因此属于电阻负载，瞬态期间电流随电压变化，并非严格恒流阶跃。记录Vout、IL、PI输出占空比D；D×Vin节点不是占空比。

## 4. 结果

| 指标 | 10 A→15 A加载 | 15 A→10 A卸载 |
|---|---|---|
| Vout最低 | 约98.7 V | 用户报告约98.71 V |
| Vout最高 | 约101.2 V | 用户报告约101.2 V；截图首峰估读接近101.3 V |
| IL关键极值 | 最大19.7989 A，截图统计 | 最小5.0995 A，截图局部统计 |
| 最终IL | 约15 A | 约10 A |
| D范围 | 约0.639–0.652 | 约0.639–0.652 |
| 最终D | 约0.645 | 约0.645 |
| 振荡基本消失目测时间 | 约50 ms | 约120 ms |

电压及占空比范围为截图估读，不能视为精密统计。截图游标差值不自动等于稳定时间。50 ms与120 ms均未绑定同一误差带，只可描述目测衰减过程，不作严格恢复时间对比。

若采用99–101 V作为分析误差带，两次进入并保持该范围的时间都早于上述目测时间，具体值待原始数据计算。±1%为项目分析口径候选，不是统一行业合格标准。

## 5. 结论与问题

1. 已测试工况下，两次扰动均出现衰减振荡并恢复至目标附近；未观察到发散或占空比限幅。
2. 加载平均电感电流峰值约19.8 A，比最终15 A高约32%。真实开关瞬态峰值还需评估叠加纹波，尚不能核定器件及磁件裕量。
3. 卸载最低平均电流约5.10 A，未见平均电流过零；不能由此证明其他工况下不会出现断续导通或反向电流。
4. 卸载后的振荡衰减更慢，表现为弱阻尼。负载电阻增大、输出级阻尼减弱是与波形一致的解释，尚未完成原因隔离。
5. 尚不能认定需要增大电感，也不能认定PI已最终整定或整机合格。

## 6. 用户问题与复习要点

以下是本轮提问暴露出的概念边界，作为复习重点，不代表能力定论。

| 用户提出的问题或判断 | 需要巩固的区分 | 正确认识 |
|---|---|---|
| 能够收敛，是否电流惯性需要增强？ | 收敛、阻尼、响应速度和电感值是不同问题 | 收敛不代表瞬态性能充分；增大L不一定改善整体响应 |
| 瞬态电流是什么？ | 稳态值与过渡过程极值 | 变化过程中暂时偏离最终值的电流；本次典型值为19.8 A峰值和5.10 A谷值 |
| 阻尼是防止突变吗？ | 抵抗快速变化与抑制振荡 | 电感限制di/dt，电容限制dv/dt；阻尼使扰动后的振荡衰减 |
| 占空比应该看哪里？ | D与D×Vin | 看PI输出o1；o是平均开关节点电压，单位V |
| 50/120 ms是否恢复完成？ | 目测消振与误差带稳定时间 | 先定义允许误差带，再找进入且后续保持的时刻 |
| 电流看起来正常是否电感安全？ | 平均模型与硬件应力 | 平均模型不包含PWM纹波，不能直接判断实际峰值、饱和或温升 |
| Cout是否应设13,200 µF？ | 母线储能电容与输出滤波电容 | 母线电容在Buck输入侧，Cout在电感输出侧 |

复习自测：

1. 负载从15 A降为10 A时，为什么输出先上升？（电感电流不能瞬变，多余电流先给电容充电。）
2. 为什么增大L不一定更好？（同电压下di/dt减小，也会减慢跟随负载需求。）
3. 为什么电感电流低于10 A后输出会下降？（负载缺口由电容放电补充。）
4. 为什么卸载后稳态D仍约0.645？（当前理想模型中稳态Vo=D×Vin。）
5. 怎样才能说恢复时间为某个数？（指定目标及误差带，从扰动时刻到进入并持续保持误差带的时间。）

## 7. 下一项单独实验

满载输入降压阶跃：负载电导固定0.15 S，Vin在1 s从155 V变为140 V，其他参数保持不变，仿真2 s。140 V是人为选取的诊断点，不是已确认母线谷值或标准要求。记录Vout最低值、IL峰值、D及统一误差带恢复时间；理想稳态D预计从0.645升至0.714附近。

后续主线：输入扰动 → 交流前端联调 → 保护与上电时序 → 开关应力/损耗/热 → EMI与安全。本实验问题保留在问题清单，不因推进下一项而视为已解决。
