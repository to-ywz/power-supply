# 可调直流电源项目

220 VAC → 110 VAC变压器 → 桥式整流及母线电容 → 同步Buck → 0–100 V可调输出。

当前仿真目标：100 V / 15 A（1.5 kW），单个86 µH电感。目录沿用原本“3kw电源”项目名称，但不代表已验证3 kW能力。

## 目录

- `hardware/`：硬件设计及原理图，目前已归档2026-10-20 PDF；可编辑硬件源文件待补。
- `firmware/`：控制固件，待同步。
- `simulation/matlab/`：MATLAB / Simulink模型、参数与运行说明。
- `simulation/multisim/`：Multisim工程，待同步。
- [实验记录](实验记录/README.md)：实验结果、截图、未解决问题及知识复习。
- `docs/`：整机验证计划与设计文档。

## 当前进展

已完成理想155 V输入的Buck平均模型启动及双向10 A↔15 A负载阶跃。实验候选参数Kp=0.005、Ki=0.1；弱阻尼和瞬态电流问题待处理。尚未完成交流前端、保护、开关应力、热、EMI和安全验证。

## 同步约定

每次实验保存模型、参数、求解设置、原始数据和实验记录；参数变化应与对应记录一起提交。SLX、Multisim等二进制工程避免多设备同时修改，编辑前先同步。大型波形数据后续按大小选择Git LFS或独立归档。

当前只进行了初始文件归档，并未设置自动同步。
